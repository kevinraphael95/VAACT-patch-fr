# Patch français du format alternatif VAACT

Traduction française amateure pour le format alternatif Yu-Gi-Oh VAACT :

https://github.com/Mazorn/VAACT-Very-Accurate-Anime-Character-Tournament-

# Installation

Rajouter ça dans le ProjectIgnis/config/user_configs.json
```
		{
		"url": "https://github.com/kevinraphael95/VAACT-patch-fr",
		"repo_name": "VAACT FR",
		"repo_path": "./config/languages/Français",
		"is_language": true,
		"language": "Français",
		"data_path": "",
		"should_update": true,
		"should_read": true
		}

```
